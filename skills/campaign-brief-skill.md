# Skill: Campaign Brief

## Purpose
Producing detailed multi-section campaign briefs for SBH campaigns — from always-on property activity through to seasonal and launch campaigns.

---

## Output Format
Detailed multi-section document. Clear headings. Prose where context is needed, tables where data is cleaner. No padding.

---

## Brief Template

---

### [Campaign Name]
**Brand / Property:**
**Brief date:**
**Prepared by:**

---

#### 1. Objective
What does this campaign need to achieve? Be specific — bookings, awareness, lead gen, database growth, event attendance. Include a measurable target where possible.

#### 2. Background and Context
Why is this campaign happening? What's the business problem or opportunity it addresses? Include any relevant performance context, seasonal peg, or strategic rationale.

#### 3. Target Audience
Who are we talking to? Reference the relevant ICP persona (Julie, Sam, The Celebrant, The Coastal Escapee) and specify whether this is a cold, warm, or retargeting audience. Note any audience segments that need different messaging.

#### 4. Key Message
The single most important thing the audience should take away. One sentence. If there are multiple messages for different audience segments, list them separately.

#### 5. Offer or Hook
The specific package, rate, experience, or seasonal peg driving the campaign. Include: offer name, inclusions, rate (if applicable), booking window, stay window, and any blackout dates or conditions.

#### 6. Channels
List every channel in play. For each channel, note:
- Objective (awareness, consideration, conversion)
- Audience type (cold / retargeting)
- Format (video, static, carousel, search, display)
- Whether it's centrally managed or Talk Agency / regional

#### 7. Creative Requirements
- Formats and sizes required per channel
- Video vs static
- Copy requirements (headlines, primary text, descriptions)
- Any existing assets available or new production required
- Brand tone reference (Spicers / Ardour / Bannisters / Worlds Apart)

## Quality Checklist
- [ ] Objective is specific and measurable
- [ ] Audience is defined by persona and temperature (cold / warm / retargeting)
- [ ] Key message is one sentence per segment — not a list of benefits
- [ ] Offer details are complete (inclusions, dates, conditions)
- [ ] Every channel has a stated objective and audience type
- [ ] Creative requirements specify formats, sizes, and copy needs
- [ ] Timeline includes all milestones with buffer for review cycles
- [ ] Budget is allocated by channel
- [ ] KPIs are defined before the campaign launches
- [ ] Approval chain is named with deadlines
- [ ] Property asset requests are specific and include a submission deadline
- [ ] Campaign is structured modularly to accommodate adjustments if needed
